GoogleForm Medallion ETL

My contribution · พัฒนาทุกขั้นตอน

ออกแบบและพัฒนา ETL ตั้งแต่รับ CSV ทำความสะอาดข้อมูล จนถึงสรุปผลใน PostgreSQL พร้อมจัดสภาพแวดล้อมด้วย Docker Compose และกำหนดลำดับงานผ่าน Apache Airflow

Bronze: นำเข้าข้อมูลดิบ (Raw CSV) เข้าสู่ PostgreSQL

Silver: ทำความสะอาดข้อความ และจัดการข้อมูลซ้ำซ้อนผ่านกระบวนการ Batch Processing

Gold: สรุปยอดจำนวนการตอบกลับและความพึงพอใจแยกตามคณะ สำหรับเตรียมจัดทำรายงาน

Target: Power BI สำหรับแสดงผลการวิเคราะห์ข้อมูล

Orchestration: ใช้ DAG แบบ Bronze → Silver → Gold กับ DockerOperator ใน Apache Airflow 2.10.5

สิ่งที่ได้ฝึก: การจัดการข้อมูลที่ขาดหาย ข้อมูลซ้ำ การโหลดเป็นชุด และการแก้ปัญหาสภาพแวดล้อม Compose / Airflow ให้รันซ้ำได้
